# 把一个问题，交给人类历史上的全部思想家

> 这是 **should-i · Ask Great Thinkers** 的产品介绍。文中的截图来自一次真实运行：
> 名录上每一个人都真跑了那 11 批，数字、名单、分布都是那一次的结果，没有重画。
> 唯一人工补上的是开头那句英文题干（本地没配 DeepSeek 的 key），平时它由模型自己写。

「如果有机会，我要去火星移民吗？」

我把这一句话丢进去。它先把这句话改写成一句能打分的命题 —— **你支持去火星移民吗？** ——
再把这同一个问题，问给名录上的**全部思想家**：不分年代、不分文化圈，一个人都不落下，
各自按自己那套框架看这件事：支持，还是不支持。

![结果：全人类怎么看这件事](wechat/04-lists.png)

结果是：

**全人类的思想家，多数反对这件事。**

93% 指向「不做」，1% 指向「做」，中间 6%。落在「支持」那一档的，只有 **27 个人**。

最支持的是马斯克 0.88、霍金 0.84、贝索斯 0.84 —— 一个几乎不需要犹豫的名单。
最反对的是卡洛·波拿巴 0.14（拿破仑的父亲，1785 年）、生态女性主义者范达娜·席瓦 0.15、
越南的嗣德帝 0.15。夹在中间还有一位很好玩的人：**巴菲特，0.16**。

有一件事要先说清楚：**这不是一次投票，这些人本人也从来没有被问过**——这是模型凭自己对这些人的
了解给出的判断。名单里每个人右边的年份，是他去世（或在世）的年份，不是这次判断的时间。

## 一次提问里，究竟发生了什么

打开页面只有一个输入框。

![提问页](wechat/01-ask.png)

丢进去一句话，二十秒后你会拿到一张图。中间那二十秒里发生的事，是这整个产品里最不显然的部分。

**第一步，把 X 说出来。**「如果有机会，我要去火星移民吗？」既没说「支持去」，
也没说是「支持还是反对去」——而下面每一个数字都是「对 X 的支持度」。所以要先有一次调用，
把 X 改写成 **「你支持去火星移民吗？」**。方向必须是「做」的那一边：
「该不该禁止短视频？」要写成「你支持**禁止**短视频吗？」，写成「不禁止」就是把 0 和 1 对调。

**第二步，把名录切成每批 255 个人。** 255 是单次请求的硬上限，所以名录有多大就切多少批
——当前这份名录切出来是 11 批，一批都不浪费。

**第三步，每个人正反两个方向各问一遍。**

只问「它指向做还是不做」，实测 **92% 会说「做」**——听起来像个结论，
其实里面混着模型对选项顺序的偏好。把「不做」换到 `true` 那边再问一遍，说「做」的比例掉到 **50%**。
两遍读法一致时正好落在 0.5，所以取中间：**分数 =（正向 − 反向 + 1）/ 2**，
每个人各自落在 0–1 上的一个位置。

**第四步，也是它敢把 11 批拼起来的原因：每批里放同一组 12 个锚。**
每一批都是 243 个名录里的人 + 同样这 12 个人，所以同一个人在 11 个不同的「公司」里各被问一遍，
他的最大差就是真正的跨请求误差。这一次跑出来是**最大 0.03、平均 0.02**——
「分十几次问出来的人能放在一起比」这句话，是当场量出来的，不是承诺。

一次提问 = **11 次请求、5610 次判断、约 38–41 万输入 token、约 19 秒**。
同一个问题第二次问是免费的：缓存键就是请求本身，答案不会变，只是不再付钱。

## 然后它铺开成一张地图

每个人一个 0–1 的数，铺在地球上，按去世年切进一条**一格一百年**的时间轴，最后一格是全部历史。

![地图：全部历史](wechat/02-map.png)

- **粉 = 支持（≥0.60），青 = 反对（<0.40），灰 = 无所谓**，点越大 = 离中间越远。
- 拖着时间轴，地图、三色条、各文化圈、两头、三张名单和直方图**整页跟着走**
  ——「17 世纪谁最支持」不需要第二次请求，就是同一批数字换了个切片。
- 地图上圆点的经纬度是出生地。**同名地点会叠在一起，所以每个点按 id 做了 ±2.2° 的抖动**——
  那是视觉修正，不是地理精度，出生地数据本来也不支持更高的精度。
- 在世的人都堆在「至今」这一年，所以最后一格是世代的递进，但「谁和谁同代」仍然看不出来。

这一格里你会看到：整张图几乎是青的，只有零星的粉点——北美东岸几点、欧洲中部几点、
东亚几点。**这就是 93% 那个数字长出来的样子。**

## 分布长什么样，比「平均分」更重要

这个产品不给你一个平均分，它给你一个分布，和一个诚实的问题：这些人到底同意到什么程度。

同一格「全部历史」里，支持 27、无所谓 142、反对 2409，**离散度只有 0.08**。
离散度低的意思是：这不是一场势均力敌的争论，是一件几乎没有争议的事。

![各文化圈的三色条](wechat/03-circles.png)

按文化圈拆开更有意思：**支持率最高的是北美（18 / 270 人，7%），最低的是日本（0 / 94 人）**。
最支持的前三名——马斯克、贝索斯、扎克伯格——都落在北美这一格里，而且都还在世。

问题也正出在这里。**西欧有 849 个人，只出了 4 个支持；北美 270 个人出了 18 个支持。**
这两件事在画面上看起来是同一种「粉色密度」，因为点本身也挤在一起。
地图上最密的区域，是名录最密的区域，不一定是意见最密的区域。
这是这个产品自己最该被质疑的地方，下面还会说一次。

## 为什么是「问所有人」，而不是做个更聪明的聊天框

大多数人第一次看到它，会问：为什么不让 AI 直接给我一个答案？

因为**问题是由你自己选的**，而你会问自己已经相信的东西。互联网答应过给我们全部的信息，
然后给了我们信息茧房——不是因为推送算法不够好，而是因为提问权一直留在你手里。
大模型把这件事放大了一层：**提问需要框架**，缺框架的人问不出好问题，
于是「对所有人开放」的聊天框，实际上只对少数会提问的人有用。而且它越贴合你，你越出不去。

所以这个产品把方向掉了个头：**让所有人回答问题。**

**提问需要框架，回答不需要**——一个人可以不知道自己该怎么活，但他知道自己支持还是反对一件事。
问题从别处来（在这里，从读者的那一句话来），每个人只给出自己的位置。
把提问权从个人手里拿走，茧房的回路就断了。

「全部」这件事也是同一个道理：**不抽样**。名录上的人一个不落，全部被问到——
这不是一句承诺，分帧必须覆盖名录里的每一个人，这条有测试盯着。

除了不抽样，它还有两件事**不做**：

- **不检索。** 检索给你的是「最像的几个」，一个排好序的子集；这里每个点都被单独给了一个读数。
- **不排名。** 地图、三百年切片、直方图、三张名单**都是同一个空间的投影**；
  「最反对的三个人」是空间的一处切片，不是检索的前三名。

## 它自己承认的短板

一个把「全部」写在标题上的东西，最该被追问的就是它凭什么叫全部。

- **「全部」是这个框架要做到的事，还不是这份名录已经做到的事。** 现在收录的是
  **2578 位**有英文维基条目的人，跨 13 个文化圈，其中一半来自西欧 + 北美 + 东欧。
  非西方文化圈用了更低的门槛才挤进来（25–60 而非 50–100），不这么做，
  中国、印度、日本、拉美、非洲加起来会不到 5%。**这不是修好了，是被压住了。**
- **这个数字还在往上走。** 名录会继续加：其他语种的维基、更低的门槛、还没被写进来的名字。
  这一步的方向是让「全部思想家」越来越名副其实，而不是把现在这个数字当成终点。
- **画面上是两位小数，但跨批次误差最大 0.055**（这一次是 0.03）。
  单个人的 0.62 和 0.58 不是一个差别，而三张名单正好是读者会把它读成排名的地方。
  **分档（0.60 / 0.40）比小数位更可信。**
- **这一页只读不写。** 没有账号、没有历史、没有分享链接。历史人物怎么想，不是关于你的证据。

## 想看它跑起来

Python 3.9+，**只用标准库**，没有依赖、没有构建步骤、没有数据库。

```bash
export TYPESAFE_API_KEY="..."   # Jev：那 5610 次判断
export DEEPSEEK_API_KEY="..."   # DeepSeek：只有一件事——把 X 说出来
python3 app/server.py           # 打开 http://127.0.0.1:8420
```

不想碰终端也行：起服务后打开页面底部的「设置 API key」，把两个 key 粘进去，点「保存并测试」，
它会各发一次真实请求，告诉你到底通不通。
