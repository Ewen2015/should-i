# Ask Great Thinkers: 把你的好奇心，让历史上所有思想家回答

![Builder: Ewen Wang](wechat/cover.jpg)

Builder: Ewen Wang

> "我写那些艰难的事情，因为我想知道自己并不孤独，也想让你知道，你也并不孤独。"
>
> —— 美国作家 Brian Doyle

痛苦来自对自身处境的过分关注，以及对宇宙的无知。只盯着自己处境的人，会把每一件小事放大成全部；而他对宇宙知道得越少，自己那点处境就越是唯一的参照系。

人类一直在向过去要经验——一个人活 100 年，看不清任何一件大事的形状，所以要读史。但「如何高效地获得」从来没有被解决过。**Ask Great Thinkers** 要做的，就是**把你的好奇心，让历史上所有思想家回答**。

> 「如果有机会，我要去火星移民吗？」

把这句话丢进 Ask Great Thinkers。它会先把问题改写成一句能点头也能摇头的话：你支持去火星移民吗？然后拿这个问题去问人类三千年文明史上的每一个有记录的思想家，每个人一个位置，摊在地球上。每个人名，就是你好奇心的思想地图。

![地图：全部历史](wechat/map.png)

![结果：全人类怎么看这件事](wechat/result.png)

预训练模型里压着人类已有的知识，聊天模型只能概括，但是 Ask Great Thinkers 基于系统一模型（Jev-like, system one model），遍历所有人类思想家。Ask Great Thinkers 相信，一个思想家就是一个提示词（A thinker is a prompt），打破信息茧房，让全人类思想家排列在你面前。
