# 名录

名录是这份产品唯一的数据。它的来源、规模和偏向都在这里。

## 名录的构成

`thinkers_data.py` —— **2578 位真实人物**，跨 13 个文化圈，**其中 399 位还在世**。
每人带出生/去世年份、文化圈、经纬度、和一句「这套框架在问什么」。

- **来源**：671 位手写核心 + 1907 位 Wikidata 导入（要求英文维基条目 + 生卒年 + 出生地经纬度）。
  导入用的是 sitelinks ≥ 50 那条线，砍掉了长尾。
- **英文维基是偏向西方的，这一步会传染。** 西欧 + 北美 + 东欧占 **50%**。
  所以非西方文化圈用了更低的门槛（25–60 而不是 50–100）；不这么做，
  中国、印度、日本、拉美、非洲加起来会不到 5%。**这不是修好了，是被压住了**：
  想要一张真正平衡的地图，得再查 zhwiki / hiwiki 等其他语言版本。
- **抖动 ±2.2° 是视觉修正，不是地理精度。** 出生地数据本来也不支持更高精度。
- **在世的人都堆在「至今」这一年**，所以最后一帧是按出生年排的世代递进，
  但「谁和谁同代」仍然看不出来。
- 名录里每个人一句的 `frame` 字段还在数据里，但**不参与任何一次请求**
  （见 [design.md](design.md) 的「只有身份，没有观点」），页面上也没有展示它。

维基链接：2578 人全部有链接，**没有一个人是点不动的**。链接由 `thinkers.wiki_url()`
在服务端拼好，浏览器从来不用名字拼 URL。
