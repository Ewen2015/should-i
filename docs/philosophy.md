# 产品哲学

> "我写那些艰难的事情，因为我想知道自己并不孤独，也想让你知道，你也并不孤独。"
> "I write about hard things because I want to know I am not alone in this
> and I want you to know you are not alone in this."
>
> —— 美国作家 **Brian Doyle**

## 上篇 · 让所有人回答问题

**痛苦来自对自身处境的过分关注，以及对宇宙的无知。** 只盯着自己处境的人，
会把每一件小事放大成全部；而他对宇宙知道得越少，自己那点处境就越是唯一的参照系。
不是要人麻木，是要有一个比「我」更大的东西可以看。

人类一直在向过去要经验——一个人活 80 年，看不清任何一件大事的形状，所以要读史。
**但「如何高效地获得」从来没有被解决过。**

**互联网答应过，然后关了门。** 结果是信息茧房。问题不在推送算法不够好，
而在**问题是由你自己选的**：你问自己已经相信的东西，它就还给你自己已经相信的东西。

**大模型答应过，但它把提问权留给了你。** 提问是有门槛的动作，需要一个人自己有一套框架；
缺框架的人问不出好问题，于是 chat 表面上对所有人开放，实际只对少数会提问的人有用。
而且它成本按人算；而且它越贴合你，你越出不去——一个以「你的问题」为中心的接口，
天然是茧房的放大器。

**所以换个方向：让所有人回答问题。** 提问需要框架，回答不需要——一个人可以不知道自己
该怎么活，但他知道自己支持还是反对一件事。问题从别处来（在这里，从读者的那一句话来），
每个人只给出自己的位置。把提问权从个人手里拿走，茧房的回路就断了。

## 下篇 · 做井，不做聊天框

**Pre-Trained Model 预训练模型是人类已有知识的一处极度压缩。** 压缩是它的价值，也是它的麻烦：
知识在里面，但它是结构化的、不能直接阅读的，只能一处一处地取。

**RLHF / Chat Model 把瓶颈留在了人身上。** 模型答、人评、人再问——这条回路里坐着的始终是人。
于是有了错位：知识已经压缩好了，取知识的带宽却还是人的带宽；人一次问一个问题，
模型一次给一个回答，对不对还要人自己判断。**人成了瓶颈，而且是极低带宽的瓶颈。**

**RLCD / System One Model 把裁判从人身上拿开。** 对比信号由模型自己产出，
不再由人一条条标出来。「大规模」是这一步的产物，不是它的目标。

**所以 Jev-Like 是电钻，不是聊天对象。** 它的价值在于能钻开压缩体，把里面结构化的判断
成批取出来。而一台电钻不构成一口井——井是**钻井平台**：怎么定位、一次钻多深、
钻出来的东西怎么摆平、怎么知道哪一钻偏了。**上层产品要做的是大规模、高速钻井平台。**

两个方向：

- **结构化挖掘，快速形成判断。** `ask great thinkers`。
- **大规模现实判断，挖掘经济价值。** 同一套结构可以搬到风控、购买倾向这类真实的量上。
