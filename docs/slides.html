让全人类的思想家回答你

对自身处境的过分关注，以及对宇宙的无知，是大部分人陷入痛苦的来源。 互联网答应过把知识给人，然后是信息茧房；大模型答应过回答一切，然后把提问权留给了你。
提问 · Chat1 个回答
提问需要一个人自己有一套框架。缺框架的人问不出好问题， 于是你问自己已经相信的东西，它就还给你自己已经相信的东西——回路是闭的。
回答 · 思想家2578 个位置
回答不需要框架。问题从别处来，每个人只给出自己的位置—— 把提问权从个人手里拿走，回路就断了。
提问需要框架，回答不需要。 一次提问 → 2578 个位置

基于 Jev-Like，做钻井平台！

钻11 批 × 255 人 × 正反两遍
矿脉
Pre-Trained Model 是人类已有知识的一处极度压缩。 知识在里面，但是结构化的、不能直接阅读的，只能一处一处地取。
瓶颈
RLHF / Chat Model：模型答、人评、人再问，回路里坐着的始终是人。 知识已经压缩好了，取知识的带宽却还是人的带宽。
裁判
RLCD / System One Model 把裁判从人身上拿开， 对比信号由模型自己产出。「大规模」是这一步的产物。
5,610 个判断 / 一次提问，而一次对话只有 1 个回答
不是一个排名，是一个全量的空间
工序
把「问一次、量很多」做成可重复的工序，而且要能当场说出这次钻偏了多少—— 每批塞同样 12 个锚，跨批最大差 0.055。
方向一
结构化挖掘，快速形成判断 —— ask great thinkers
方向二
大规模现实判断，挖掘经济价值 —— 风控、购买倾向
