# 页面

页面本身：地图、时间轴、面板，以及视觉语言。

- 进入后 **3-2-1 倒计时**，三个数字各占**整整一秒**，然后封一个「判」，开始扫描。
  - 数字是白的，进场的头 0.4 秒裂成**品红和青**——就是页面上「支持 / 反对」用的
    那两个颜色——然后合拢成白色。下面那条**刻度尺**按同一个时钟填满，
    所以数字和尺子不可能各说各的：实测每个数字 0.99–1.00 秒。
  - **倒计时是等待的封面。**「判」封上之后不落，一直到这次运行真的可以发请求为止——
    开头那次题干改写是串行的，冷的时候要 7 秒。超过 2 秒，「判」下面开始报秒数
    （`判 / 正在核对题干 · 已等 5 秒`），所以等多久都看得出在等，而且尺子会开始呼吸
    （「数完了」和「还在等」是两件事，动起来才分得清）。
  - 系统开了「减弱动态效果」时，分裂和呼吸都关掉；数字仍然是实打实的 3 秒。
- **有音效，但没有一个音频文件**：每一声都是当场按这一页正在画的数字现算的。
  倒计时三个数字各一声、音高往上爬（3-2-1 是走上跳台，不是被数下去），
  封「判」那一下低五度、更长；扫描时**每一百年一声**——音高取那一百年的平均分，
  音量取这一百年有多少人（六个人的一百年不该和三百个人的一样响），而且全部落在同一条五声音阶上，
  所以任意两个世纪挨在一起都不会难听：这个顺序是名录排的，不是人排的。
  最后一个音是**全部历史**的和弦。拖时间轴不出声，那是读者自己的手。
  - **关掉它，这一页画出来的东西一模一样。** 这是同一个测量的第二种渲染，不是盖在上面的一层情绪。
  - 「音效」开关在**工具栏里**，和「重播」同一排：扫描和它的声音是同一次运行，属于同一组控件。
    它在第一声响起时就已经在屏幕上，所以想静音的人不用等；开始按钮旁边**不放**——
    那一屏只该有一个要按的按钮。选择记在浏览器里；系统开了「减弱动态效果」时默认不出声。
- **地图上面那行大字是改写过的，不是用户的原话**，下面小字是原话。
- 世界地图用 **Natural Earth 110m 陆地轮廓**（烤进页面），圆点才是真数据。
- **一格 = 一百年。** 整条时间轴 32 格（公元前 1100 到 2026，按去世年切），
  **最后一格是全部历史**。一格之内按去世年依次亮起。
  **粉 = 支持（≥0.60）、青 = 反对（<0.40）、灰 = 无所谓、暗灰 = 还没测到**，
  点的大小是**离 0.5 有多远**。
- **空的一格会说它自己是空的**：这一百年名录上没有人 / 还在等分数 / 拿到了分数但没回来，
  三种「没有」分开说。
- 地图下面是**三色条**（这一百年多少支持 / 无所谓 / 反对），再下面是**各文化圈**同一百年里
  的三色条，再下面是**这一百年的两头**（最支持的那个、最反对的那个，带维基链接）。
- **拖着时间轴，整页跟着走** —— 地图、三色条、文化圈、两头、三张名单和直方图。
  所以「17 世纪谁最支持」不需要第二次请求，就是同一批数字换了个切片。
- 面板里是**三张名单**（最支持 / 最无所谓 / 最反对）、**分数直方图**、以及
  **那 12 个锚落在哪儿**。同名地点会叠在一起，所以每个点按 id 做确定性抖动 ±2.2°。
- **直方图有轴，而且两端写明了方向** —— 左边 `反对 0.00`（青）、右边 `1.00 支持`（品红），
  用的是上面那三张名单同一套颜色块。以前柱子按边上了色，但两端没有名字，
  读者得自己从颜色反推这个刻度是往哪边走的。
- **锚点的按钮和它的后果在同一个地方。** 「锚点 12 人」在直方图右上角，
  换完人以后「用新锚点重跑」就出现在正上方。按钮原来在标题工具栏里，
  跟着它一起搬过来 —— 搬走以后实测按钮和提示之间隔着 **1834px**，
  也就是说读者改了尺子，唯一告诉他这件事的那句话在屏幕外。
- 结论是**每次重画时现算的**，不是从 Jev 直接拿的。人数少的时候它会说
  「这一百年只有 6 个人，构不成一个分布」，而不是把 5 比 1 报成「多数赞成」。
- 支持 / 无所谓 / 反对的**分档阈值**是 `TK_SCALE_HI = 0.60` / `TK_SCALE_LO = 0.40`，
  0.5 是「两遍读法一致」，不是「没意见」——页面上写明了这一点。
- 关闭 JavaScript 后页面打不开任何数据：这一页是纯前端渲染的，没有服务端预渲染版本。
- 支持深色模式（跟随系统）。视觉语言照 [typesafe.ai](https://typesafe.ai/)：
  ink `#1E1E1E` / paper `#FEFEFE` / 粉色 `#F386A1` 的抖动渐变天空条、Win95 风格窗口。
